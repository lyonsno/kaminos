What happens when you press Apply?

There is no hidden model and no visual trick. The example uses a hand-written operation so every part of the integration is easy to inspect.

  1. Share one deviceThe renderer and the brightness operation declare what they need. The application creates one GPU device that satisfies both.
  2. Read the pixelsThe photograph becomes a list of red, green, blue, and transparency values.
  3. Queue one jobThe application asks the kit to run the brightness adapter with your selected multiplier.
  4. Run on the GPUA small compute kernel multiplies the color channels and clamps them to the image's valid range.
  5. Display the resultThe processed pixels return to the application and appear beside the original. Apply again to reuse the same device and rendering service.

Where should I look in the code?

Open the worked example module. Start with createRenderPlusInferenceExample(), then follow createBrightnessModelAdapter() to the three-step upload, compute, and readback path.

The same kit interfaces can host larger model ports. This example deliberately keeps the operation small enough to understand in one sitting.
