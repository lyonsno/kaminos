# Operator Image Browser

Static `file://`-compatible browsing pages for every PNG, JPEG, and WebP under the skull-muzzle artifact family at generation time. The browser groups images by assay, preserves artifact-relative paths, and supports path search, image-kind filtering, thumbnail sizing, and full-resolution modal inspection.

Inclusion is inventory evidence only. It does not promote an image or establish visual quality, source fidelity, route health, or spatial validity.

Rebuild and verify:

```bash
node build-browser.mjs
node test-browser.mjs
```

Open `index.html` for assay navigation or `all.html` for the complete flat inventory.
