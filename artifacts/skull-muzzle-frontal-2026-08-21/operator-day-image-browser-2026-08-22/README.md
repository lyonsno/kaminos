# Operator Image Browser

Static `file://`-compatible browsing pages for every PNG, JPEG, and WebP under the skull-muzzle artifact family at generation time, plus a canonical spatial atlas containing every skull-family `output.glb` and the named full-body and implementation controls. The image browser groups images by assay and supports path search, image-kind filtering, thumbnail sizing, and full-resolution modal inspection. Every spatial record binds its GLB to a labeled input image, effective settings, surviving camera witnesses, copyable absolute Blender path, direct KamiNOS route, and claim ceiling.

Inclusion is inventory evidence only. It does not promote an image or establish visual quality, source fidelity, route health, or spatial validity.

Rebuild and verify:

```bash
node build-browser.mjs
node build-cross-family.mjs
node test-browser.mjs
```

Open `index.html` for assay navigation, `all.html` for the complete flat image inventory, or `spatial.html` for the canonical spatial-cast atlas. `skull-spatial.html` is the skull-only saved view; `cross-family.html` is the focused high-resolution/control comparison.
