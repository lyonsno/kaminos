# Operator Image Browser

Static `file://`-compatible browsing pages for every PNG, JPEG, and WebP under the skull-muzzle artifact family at generation time, plus a spatial atlas for canonical generated `output.glb` runs. The image browser groups images by assay and supports path search, image-kind filtering, thumbnail sizing, and full-resolution modal inspection. The spatial atlas binds each GLB to its labeled input image, effective settings, surviving camera witnesses, copyable absolute Blender path, and direct KamiNOS route.

Inclusion is inventory evidence only. It does not promote an image or establish visual quality, source fidelity, route health, or spatial validity.

Rebuild and verify:

```bash
node build-browser.mjs
node build-cross-family.mjs
node test-browser.mjs
```

Open `index.html` for assay navigation, `all.html` for the complete flat image inventory, or `spatial.html` for the paired spatial-cast comparison surface.
