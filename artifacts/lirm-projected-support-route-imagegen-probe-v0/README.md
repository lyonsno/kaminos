# Projected Support Route Imagegen Probe V0

This probe tests whether generator-facing low-frequency body geometry can invite
a coherent support-bearing creature while support identity remains outside the
projection in semantic sidecars.

## Result

All four FLUX outputs were agent-inspected and classified
`happy-safe-friendly-organism`. The outputs use sparse, broad, attached supports
and preserve one continuous organismal body. The matched-seed pairs also show
visible low-frequency mass authority:

- Seed `725101`: the base body remains longer and lower; the heavy body becomes
  substantially more compact and centrally massive.
- Seed `725102`: both outputs share a friendly toy-creature basin; the heavy
  body remains stockier while the base body spans farther between supports.

The route-around therefore buys two independently useful properties in this
assay:

1. generator-facing projections avoid the repeated partial-support cues that
   previously invited hostile completions;
2. bow-plan mass variation remains visible after image generation.

The assay does not yet establish exact support correspondence between semantic
sidecars and hallucinated limbs. That belongs to the next mapping exercise.
