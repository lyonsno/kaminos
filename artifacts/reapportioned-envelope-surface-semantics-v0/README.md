# Reapportioned envelope surface-semantics assay

This is a matched 4 x 3 FLUX assay over one operator-selected conditioning image. It asks whether the same authored external morphology can retain its silhouette while the generator assigns a deformable surface (`fur`) or three materially different rigid-component priors (`armor`, `shell`, and `stone`).

The source screenshot is deliberately preserved pixel-for-pixel. Its incidental Blender viewport marks are part of the fixed input, not an admitted visual target. Every cell uses the same source, model, dimensions, steps, guidance, and quantization; only prompt and seed vary.

The first useful result is not whether any single creature looks polished. It is whether the prompt family yields repeatable separation between deformable and rigid-looking regions without destroying the operator-authored silhouette. Any positive result opens the later SAM/VLM rigidity-classification branch; it does not itself prove that branch.

The completed operator-facing matrix is `operator-assay-sheet.html`. It places
all twelve original-source outputs and both revised-source morphology canaries
beside their exact prompts, settings, seeds, job identities, and conditioning
images.
