# Titan Hammer Source Repair

Date: 2026-07-13/14 UTC
Agent: `handy-candyman`

This episode tested whether the Crucible Bench Titan Hammer could improve by repairing the source image before reconstruction. The authoritative family source remains the operator-smoked Crucible Bench splat from the Crucible Bench workspace direction packet; this folder works from the prior isolated hammer source and mask in `artifacts/titan-hammer-source-cleanup-2026-07-13/source-cleanup/`.

## Result

No new hammer cast was promoted.

The prior promoted cast remains:

`artifacts/titan-hammer-source-cleanup-2026-07-13/promoted/titan-hammer-sf3d-white.glb`

Two Greenroom SF3D re-firings produced usable evidence but not a better asset:

- `sf3d-repaired-max`: deterministic dark-artifact attenuation source; viewer loaded and registered the GLB, but the handle retained severe black patches and the head read less clearly than the prior cast.
- `sf3d-neutral-rebuild`: procedural neutral material repaint from the source mask silhouette; viewer loaded and registered the GLB, and the silhouette was cleaner, but the tan handle collapsed to a near-black column.

Both are preserved as useful misses. They should not be described as promoted or freely accepted production casts.

## Next Boundary

The next hammer improvement should not keep pushing deterministic dark-patch attenuation. The useful direction is a source-generation or repair pass that preserves the clean mask silhouette, keeps the hammer head legible, and forces a readable tan handle before the next SF3D or Trellis firing.
