How it works

A WiLoR hand detector locates the hand; MobRecon reconstructs its shape. Both neural networks run as WebGPU compute shaders using Kaminos WebGPU Inference Kit. With no accepted detection, reconstruction pauses and the mesh disappears. This shows hand shape and articulation, not calibrated world position.
