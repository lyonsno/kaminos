# LERMS Terrarium

This is the first Kaminos world cartridge scaffold. It packages a lerms-shaped
world surface for Underhill terrain, little bodies, goins, hand surfaces,
finger-fluid experiments, motion passes, generated props, and operator smoke
offers.

Open direction:

```text
?world_cartridge=lerms-terrarium&world_chamber=lerms-underhill&posture=inspect&bench=terrain-preview
```

The cartridge is a forge-side composition surface. Agents extend it by opening a
Kaminos worktree, adding scene recipes or affordance bindings, exercising the
same route the operator will smoke, and recording a graduation mode.
