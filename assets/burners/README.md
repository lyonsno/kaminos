# Burner library

Crown (ring), Seam (slot) and Lance (angled nozzle) are the original Hotwet burner geometry studies from `c9915c0a1f8fb4ab90e35605674dac9298cd855f`. Source recipe: `examples/burner-designs/generate.mjs` on `cc/hotwet-burner-designs-1024`. `designs.json` records source dimensions, outlet poses and SHA-256 hashes; its comparison-file entry describes a producer artifact that is not bundled here.

The three GLBs are copied without conversion. Named parts and `proposed-emission-opening` nodes remain in their original local metre coordinates. The ordinary mesh importer controls placement/scale. These assets do not create or bind simulation emitters.
