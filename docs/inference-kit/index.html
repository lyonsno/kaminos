Kaminos WebGPU Inference Kit

Run generative and vision models locally in responsive browser applications.

A shared runtime for GPU devices, model loading, queued inference and cooperative scheduling. Try a model below, or use the kit to build your own application.

Try it in your browser

Generate an image with FLUX

Type a prompt and watch FLUX.2 [klein] 4B generate an image on your GPU. The text encoder, four diffusion steps and image decoder all run in the browser.

Generate an image Model guide

First visit: 3.9 GB of weights, cached for later runs. Use a WebGPU-capable browser.
