# Skeleton proportion reference atlas

The `marionette/rest-skeleton` Workbench accepts an optional `proportion_atlas` in its normal editor input. The contextual inspector compares actual rest-joint origins as the person edits. Reference choice uses shared Undo/Redo, retains the reference object's placement, and saves with **Skeleton file → Save skeleton…**. Opening that saved skeleton restores the atlas, chosen reference, source identities and authored geometry. Opening an older saved edit with the exact same named parent graph retains the current atlas if the file has none; a different graph uses its own declared comparison or remains unsupported. Ordinary Scene Save still does not reconstruct rest anatomy.

`experiments/creature-motion/skeleton-proportions.mjs` owns the deterministic measurement contract. `measureSkeleton(skeleton, profile)` accepts `{joints:[{name,parent,head}]}` or a reference's `{jointNames,parents,positions}`. `profile` is explicit `kaminos.quadruped-correspondence.v1`: `id`, `authority`, a two-landmark `trunk`, and `fore`/`hind` objects each with `left`/`right` ordered semantic chains of at least three landmark names. Chains may span intermediate graph joints; measured length follows every actual origin edge. Rest bends use the first three declared landmark positions and are not joint limits. Bone display tails, scene placement and camera are excluded.

The first descriptor comprises shoulder/hip widths divided by trunk endpoint distance, their ratio, total fore/hind chain lengths and ratio, first segment fractions, first rest bends, terminal-segment angles to trunk forward, and bilateral chain-length differences. Terminal direction requires at least four declared chain landmarks: the last edge is caller-designated distal structure, not an inferred foot. Its angle distinguishes forward, perpendicular and backward, but does not recover a full 3D foot orientation. Reach is chain length, not IK reach or a physical feasibility claim. The exact landmark definitions and supplied authority matter: different distal endpoint conventions change chain fractions. Widths are distances between bilateral limb-origin landmarks, not thorax or tissue breadth. L/R length difference does not detect all positional asymmetry; its UI uses percentages of mean chain length and absolute percentage-point deltas, not relative amplification against near-zero references.

The atlas schema `kaminos.skeleton-proportion-atlas.v1` holds candidate `profile`, `activeReference` and `references`. Each reference has a unique `id`, `label`, `source:{path,sha256}`, raw graph/positions and its own `profile`. Source identity belongs to the caller; when served through the normal digested recipe it is bound to that input, not independently authenticated against an external file by the measurement module. The live reference object exposes active identity in `userData.proportionReference`, while the scene registration names the caller's atlas. A partial correspondence yields missing cells and reasons; unknown correspondence yields `unsupported`. An otherwise editable body whose geometry cannot be measured returns `unmeasurable` with diagnostic cells while preserving read/edit/Undo. Invalid atlas configuration still fails load. There is no validity score, nearest-reference rank or automatic correction.

Headlessly, use the same saved skeleton or editor input:

```sh
node scripts/skeleton-proportions.mjs --input /caller/skeleton.json --out /caller/proportions.json
```

The caller chooses both paths. Inline editor input, saved skeleton, and digested `plan_url`/recipe envelopes resolve through the same `loadRestEditorInput` used by the browser. Relative URLs additionally require an explicit `--base-url http://127.0.0.1:<port>`; digests apply to effective fetched bytes. The report retains input digest, resolved URLs, effective deterministic route, measurement and failure phase even when resolution/measurement fails. It invokes no model and makes no anatomy or motion-support inference. The interactive experiment's `proportions` operation returns the same measurement. Optional soft constraints and a measured motion-support envelope remain subsequent work, not capabilities of this first comparison tool.

## Editable starting bodies and body structure

**Start from** branches into the opened skeleton or an exact available reference graph. It is an ordinary Undo action: it changes the editable body, not the independently movable reference. Cat/Dog names, parent indices and displayed rest origins are retained without topology retargeting; the caller's reference provenance and uniform-scale/pelvis-aligned presentation remain explicit. These are editable reference rest bodies, not newly generated motion. Save skeleton retains the authored body, explicit symmetry pairs, original exemplar identity and atlas. Undo/Redo works across body changes and intervening joint edits. Older saved bodies keep their original names and coordinates.

In Tab/Edit Mode, **Body structure** follows selected forelimb, hindlimb or axial landmarks; its selector can select the corresponding structure. Fields use the current body's trunk length, excluding scene placement. Paired origin width/height/fore–aft position translates whole branches and preserves limb lengths. Reach scales each branch about its origin. Segment length changes the selected actual edge and translates its descendants, preserving other edge lengths. First-segment fraction redistributes the existing chain length without changing its total. These operations are deterministic geometry edits, not anatomical constraints. Complete explicit correspondence and adjacent segment landmarks are required; unsupported geometry reports why rather than guessing.

Trunk length is a factor relative to the start of the gesture. Hold pelvis or the front trunk landmark translates limb branches without stretching them. Hold terminal feet preserves each chain's last two points and their descendants, changing limb lengths and rest angles; it is not IK or ground contact. All numeric fields reuse shared drag/type ergonomics and shared gesture history, including Escape, one-step Undo and nonaccumulating previews. Viewport G/R/S remains direct joint editing; source Cat/Dog symmetry includes their declared L/R labels.

Agent operations use the same path: `startFrom({id})`, `structure({part:'fore'|'hind'|'trunk'})` and `shape({part,property,value,index?,pin?})`. Limb properties are `width`, `height`, `forward`, `reach`, `proximalFraction` or `segment`; `index` selects a segment. Trunk uses `property:'length'` and `pin:'pelvis'|'front'|'feet'`. `startFrom` refuses an active edit; `shape` requires Edit Mode and uses an existing gesture's original snapshot when one is active. No model, cast binding or motion regeneration is invoked.
