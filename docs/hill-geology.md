# Formed Hill landscape

Open `?workspace=workbench&experiment=hill-geology` in Kaminos. The experiment mounts the formed rock and loose-earth surface in the native scene. The earlier `hill-terrain` experiment remains available for comparison.

The initial terrain is a stitched multi-tile geological territory (`32×32 = 1,024` tiles by default across a `385×385` grid) with authorable plateau/mesa caprock tablelands, stair-stepped structural terraces, conjugate box-canyon corridors, tilted hogback ridges, and a scalloped range front grading into a low-gradient piedmont apron before a broad front outlet. Seeded tectonic strike azimuths, massif shifts, and trunk breaches reorganize the macro-topography across seeds while routing drainage continuously across all tile seams. A priority flood supplies spill routes through depressions; an acyclic multi-receiver drainage graph accumulates contributing area and partitions flow across steepest downslope neighbors on the upland and broader fan neighbors on the apron. Above the chosen channel source area, stream-power incision removes loose material first and then rock, modulated by buried strike-rotated, tilted, folded, and bench-capped resistance bands, caprock tread armoring, and base-level relief. Deposited sediment increases local slope and carrying capacity across a continuum fan reach, bifurcating across lower apron neighbors to build a coalescing alluvial bajada without grid-scale spikes. Humped regolith weathering converts bedrock to loose cover under thin moist soil while insulating bedrock under deeper cover and slowing on bare resistance ledges. Exposed over-steep rock banks fail locally into neighboring loose talus while competent caprock cliffs hold steep mesa rims and terrace risers, and steep bedrock scarps shed loose cover so rock ledges and canyon walls stay exposed across extended formation runs. Sediment leaving the open outlet is accounted separately. All other edges are closed to fluvial export.

This is a reduced formation model, not calibrated geological prediction. Formation steps select a geological epoch along a non-convergent transient erosion curve rather than converging to a static equilibrium, and have no claimed duration in years. Rainfall is implicit and spatially uniform, the channel threshold approximates channel initiation, and bedrock and loose material use equal volume density. No chemical species, groundwater, suspended-fluid dynamics, ice or volumetric fracture is simulated; local bank failure is a height-field mass transfer. The two mechanical layers retain a procedural stratigraphy description; their representation remains a single surface per horizontal sample. Rock color follows that same strike-rotated stratigraphy; cover thickness controls how much is exposed.

## Preparation and caching

Formation is separate from live playback. The bundled default is a prepared binary cache. New settings run the identical deterministic formation module in a dedicated CPU worker; when advancing `Formation age · steps` or clicking `Step formation` on the same recipe, the worker resumes from the current formed state and streams partial terrain states to the GPU viewport while forming. The worker terminates on completion, disposal or superseding settings. Generation is a preparation cost, not part of the game frame loop. Automated qualifying preparation and numerical browser runs go through Greenroom.

Memory and IndexedDB caches are keyed by the complete normalized recipe and solver version. The binary stores a JSON header and float32 material state with a payload checksum. Load rejects incomplete/corrupt data, mismatched recipes and unsupported solver versions. A persistent-storage failure is visible and leaves the computed result usable in memory. Solver changes that reinterpret results require a version change. The cache represents the **formed initial landscape**, not later live edits; velocity and actor-memory channels are zero.

Default: `32×32 = 1,024` seam-locked tiles across `385×385` samples (`8×9` world units), `294,912` triangles, approximately `2.26 MiB` on disk (`2,372,176` bytes). The shared GPU instance owns `18,973,184` bytes of storage arrays plus `3,538,944` bytes of tile-grouped triangle indices, excluding renderer/shadow/driver allocations. Initialization uploads the cached material fields and derives geometry, normals and colors on the host WebGPU device. Idle terrain dispatches no evolution. Optional settling uses the existing GPU transport and interpolation; no terrain state is read back in playback, controls or rendering. The 60Hz composed game budget remains unmeasured.

The same file contract works outside the browser:

```sh
node tools/hill-form.mjs --config experiments/hill-terrain/cache/default.recipe.json --output /chosen/path/landscape.hill
```

The tool writes a terminal `.report.json` on success or failure, with effective recipe, source hash, output checksum and material accounting. Run it through the shop queue for substantial configurations. `encodeFormation`/`decodeFormation` are shared by the tool and browser. The Workbench `recipe` operation returns the current inputs; `cache` returns the encoded initial state. These are not evolved-state checkpoints or scene-document reconstruction.

## Controls and integration

Curated geological presets (`Canyonlands Mesas & Terraces`, `Grand Staircase Structural Terraces`, `Isolated Buttes & Dissected Badlands`, `Cuesta Hogbacks & Water Gaps`, `Peaked Range & Coalescing Bajada`) and grouped authoring controls (seed, formation age, initial relief, plateau & mesa cap, structural terracing, major canyon systems, receiving apron, rock-bed tilt, strike angle, folding, thickness, resistance contrast, channel source area, stream incision, and weathering rate) expose bounded `[min, max]` sliders alongside scrubbable number inputs, default badges, and plain-English physical tooltips. A 3D tile-seam overlay (`Show 1024-tile seams`) visualizes the stitched `32×32` tile partition directly on the terrain surface. Rebuilding replaces the initial terrain and resets optional settling. Native scene selection, transforms and camera navigation remain available. Framing uses an initial envelope; exact CPU surface picking and geometry export remain unavailable because they would consult stale CPU geometry.

`window.kaminosHillGeology.read()` distinguishes requested inputs, effective formed recipe, cache source, pending work and GPU provenance. `.gpu()` supplies the existing same-device height/material surface and local-to-world transform. `.snapshot()` is an explicit offline numerical witness only. Initial rock/soil and geological preparation are not player or creature history. Fluid and creature interaction are later composition work.

## Verification

```sh
npm test -- --only tests/hill-formation.mjs,tests/hill-formation-cache.mjs,tests/hill-geology-witness.mjs,tests/hill-terrain.mjs,tests/hill-terrain-experiment.mjs,tests/hill-terrain-witness.mjs
```

The tests cover deterministic formation, drainage exits/cycles, material accounting, channel initiation, uniform-slope stability, excavation-sensitive rock resistance, cache corruption/recipe mismatch, cancellation and GPU source admission. `tools/hill-geology-witness.mjs` takes explicit `--url`, `--root`, `--out`, `--browser`, and `--playwright` paths. It compares the actual GPU state with the retained cache, checks idle stability and cache reload, exercises native controls and a worker-generated configuration, captures the scene and checks disposal. Raw arrays and source/config identities are retained. Numerical checks do not establish visual plausibility; inspect the native frames.

Formation references: [Cordonnier et al., uplift and fluvial erosion](https://perso.liris.cnrs.fr/apeytavi/website/publication/hal-01262376/), [Sculpting Mountains, subsurface geology](https://pubmed.ncbi.nlm.nih.gov/28368822/), and [Yoo et al., hillslope weathering and sediment transport](https://www.usgs.gov/publications/spatial-patterns-and-controls-soil-chemical-weathering-rates-along-a-transient). These motivate the process selection; this implementation is not a reproduction of those full models.
