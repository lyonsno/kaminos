# Finished wood fiber study

Open `?workspace=workbench&experiment=wood-fiber` on this branch. The left slab uses the measured diffuse color with the host GGX surface model. The right adds the analytic subsurface fiber term from Marschner et al., *Measuring and Modeling the Appearance of Finished Wood*, SIGGRAPH2005. Change Fiber strength to zero to compare the same right-hand surface, move Light angle, or orbit through the shared camera. Number fields support drag and click-to-type; edits apply live.

This is a material study using measured flat patches, not recovered TRELLIS material or a solid wood volume. Box faces repeat the patch. The fiber term participates in the host's direct scene-light evaluation; environment illumination retains the host surface model. The surface GGX term differs from the original RenderMan shader, so this is not a reproduction of the paper's complete renderer or an energy-conservation claim. It is not integrated with the custom flame irradiance path. No performance result has been established.

Source: https://www.cs.cornell.edu/~srm/publications/SG05-wood.html . The downloaded author archive supplies diffuse color, fiber axis, fiber color and beta (highlight width) maps. The GLSL/WGSL math is independently expressed from the published model. The author maps remain local research assets; no redistribution license was established. No author map is committed here.

The default manifest is mounted through generated-meshes at `wood-fiber-study-1108/manifest.json`. It records the original source and SHA256 of each binary map. Each file is little-endian RGBA float32, derived from the 16-bit linear TIFF without resampling. Upload uses half-float textures; the fiber scale20 and axis conventions follow the author shader. An identical central UV window selects all four channels, avoiding acquisition borders and marks. Original files and complete converted maps remain retained. Missing files or content hash mismatches refuse the experiment.

Pass a different manifest and sample through `experiment_inputs`. Available local samples are `cmaple`, `padauk`, `walnut1`, `walnut2`. Inputs also retain initial `fiberStrength`, `roughness` and light `azimuth`; live edits can be read from `window.kaminosWorkbenchExperiments.read()` and supplied on reopening. Experiment close removes its registered slabs and fixture light. General scene Save does not reconstruct this custom material; reopen by experiment inputs.

Run `npm test -- --only tests/wood-fiber-native.mjs`. The test executes the production WGSL on Apple WebGPU and checks the fiber cone, inclination, backlighting and grazing finiteness. A valid compiled disconnected-contribution control must fail the optical expectation. This tests the local lobe, while the Workbench browser exercise tests texture loading, actual rendering, controls and close/reopen. It is not a frame-budget benchmark.
