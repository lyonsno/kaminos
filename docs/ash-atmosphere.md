# Scene-wide airborne ash

Open the **Ash — across the scene** Workbench experiment (`ash-scene-cloud`). It composes the existing kiln, local GPU deposit/contact fixture and falling source with camera-following fine flakes and analytic distance haze. The new experiment defaults to a .03 local deposit cell width, independently of .009 fine flake width; the earlier GPU contact experiment retains its .012 default.

The cloud has no particle-state buffer, readbacks or compute dispatch. A stable integer seed, time and wind determine each instance's world position in a camera-centred wrapping volume, initially 24×12×24 world units. Ordinary camera movement preserves interior world positions. Recycling fades over the outer 16% of that volume, and flakes fade near the camera and ground. These distant flakes represent airborne appearance; they are not conserved ash mass and do not collide with arbitrary geometry. The local falling source remains the separate conservative transport into retained deposits.

Fine flakes use one instanced transparent plane draw in each applicable scene pass, depth-tested against the scene, with a soft elliptical opacity mask. Initially 24,000 instances use 1,536,000 bytes of renderer-owned instance matrices; no per-flake simulation state is allocated. Count changes can enlarge that allocation. Receipt fields report actual allocation and requested settings; this is not zero GPU work or zero storage.

Haze uses Beer attenuation `exp(-density*distance)` in the existing material fog channel. Colour/node backdrops are blended toward the same haze at an assumed distance of 60 units; texture backdrops are preserved. The existing flame draw applies the same density in local ray units, with its transform scale included. Its premultiplied colour is attenuated and receives only the fog obscured by its own alpha, avoiding a second fog layer over an already-fogged scene. This treats the flame volume at its front face. It is a thin-layer presentation approximation, not a new volumetric scattering solve. Residual/optical source captures remain unchanged. Flame haze colour follows the scene's AgX camera and exposure; the receipt identifies other scene-camera choices as unmatched.

The host carries haze settings while fire is absent and hands them to Kaminos's lazy fire runtime when it starts. Closing releases the owned scene resources and restores borrowed fog/background/flame settings. A scene with an already claimed fog channel is explicitly rejected. This prototype owns no general arbitration between multiple atmospheric producers.

`atmosphere`, `cloudTime`, `cloudPlay`, `wide`, `view` and the inherited local ash operations use the same Workbench agent-callable path as the controls. `Save ash` includes the local retained checkpoint, cloud settings and cloud phase. This does not add atmosphere persistence to ordinary scene files. Automatic updates use the shared scene frame callback.

`?ash_timing=1` enables the renderer's existing timestamp collection. `renderProfile` reports Three render passes since the previous resolve, excluding raw ash compute and the separate flame canvas. `tools/ash-cloud-witness.mjs --profile yes` is a benchmark and belongs in Greenroom. It records Retina drawing size, paired repeated cloud-off/on render samples, local compute cost, and—when a saved basin is supplied—same-field flame GPU timestamps. These measurements must be composed before claiming an approximately 1 ms total increment. Neither absent cloud simulation nor a small flake count establishes that budget.
