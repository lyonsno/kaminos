# Creature courtyard

The Workbench experiment **Creatures · furnace courtyard** mounts a stone court, carved arch, two bronze objects and the ordinary living-creature consumer around the authored flame. Select and place objects through the native editor. The creature cohort uses Strong Walk and Lean/TRELLIS rolling stroll preparations with the composed physical encounter route.

The flame retains its ordinary emitter, simulation, pause and rendering controls. Opening the courtyard, holding creatures or restarting them does not pause, step or take ownership of the fluid solver. The courtyard supplies no whole-world step button. **Run scene** controls the creatures through their existing owner.

**Run timed objects** separately enables the optional 48-second event program. It uses the viewer frame service, independently of creature playback and the number of fluid steps completed. Events edit the native source feed, visibility, size and motion state. For an immersed source, the program’s `flow` value multiplies the initially authored inlet speed; zero disables source emission while the fluid keeps evolving. For a boundary source it edits the ordinary Flow coefficient. Source growth and decay remain the real solver's response. Event times and the actual flame runtime are retained separately in the observation; this is not exact fluid replay.

Select **Bronze iris beacon** to edit its visibility and size. Select **Crossing bronze lantern** to edit movement, travel speed and travel width. Both expose **Follow timed events** in their object inspector. Editing a source releases that source from the program, while other sources can continue. The actual flame source has its normal inspector plus the same optional timer participation. Accepted native source edits, including inlet-speed changes, release its timer and enter the shared history. Scheduled source edits carry their origin and keep following the program. Move all objects using ordinary transforms; the lantern path retains authored placement edits. The advanced event program accepts valid JSON edits automatically.

**Repeat object events** restarts the program and analytic lantern phase while preserving creature experience. **Restart creatures** reconstructs the original cohort and leaves the independent sources running as they were. Neither restores a fluid checkpoint. Removed props stop participating in their timer without stopping the other objects, creatures or flame.

Select a creature and open **Senses & concern** for candidate gates, distance, gaze attenuation, sensory strength, familiarity and motivation. The optional field drawing shows gaze and angular extent at a display length of two world units. Actual distances remain in the inspector. The visibility model uses angular/distance and bounding-sphere proxies, without occlusion. Light readouts distinguish status time from measurement time.

**Save observation and event history** downloads the shared recording, current creature/source state, observation coverage and courtyard command log. Recorder `complete` describes retention of received operations; it does not claim universal world coverage or evolved-fluid replay. The authored scene is `courtyard.scene.json`; the cohort and program are `courtyard.setup.json`, next to the experiment. Experiment-created procedural pieces retain the shared experiment's reconstruction/lifetime contract. Ordinary authored scene saving is not an evolved simulation checkpoint.
