# Creature courtyard

The Workbench experiment **Creatures · furnace courtyard** composes the ordinary living-creature consumer with a flat stone court, perimeter columns, two registered props and the scene's authored flame. The baseline scene is `experiments/creature-motion/courtyard.scene.json`; the cohort and event program are in `courtyard.setup.json` next to the experiment. The baseline uses the existing Strong Walk and Lean/TRELLIS rolling stroll preparations. Architectural pieces lie outside the walking region; the experiment does not add a static collision or navigation solver.

Run/Pause scene holds the creatures and scheduled events together. Events use scene simulation seconds and are applied before the creatures observe each boundary. Exact advance also processes crossed events in order. The default 48-second program changes source flow, makes the nearby beacon appear and expand, then moves a bronze lantern. It edits the real sources, with no scripted creature actions. Fire growth and decay still belong to the fluid solver and can lag the source command.

**Repeat events · keep experience** restarts the event program while retaining the creatures' memories, positions and motivations. **Restart creatures and events** pauses the scene and reconstructs the initial creatures. Neither restores an evolved fire-field checkpoint. Manual source edits hold automation while creatures can continue; Resume schedule continues the held program. The event program is editable JSON. Ordinary scene selection and transforms move the props.

Select a creature and open **Senses & concern** to inspect current source gates, distance, gaze attenuation, initial sensory strength, attention score, familiarity and motivation. The optional selected-creature field draws gaze direction and angular extent at a fixed display length of two world units. Actual notice distances remain per-source values in the inspector. These are angular/distance and bounding-sphere proxies, without an occlusion or retinal rendering claim. Light diagnostics expose the probe status, sampling time, luminance and received change.

**Save observation and event history** downloads the shared investigation recording plus current creature/source state and the complete courtyard command log. Event entries identify their simulation boundary and label creature observations as preceding that boundary's creature step. The shared recorder also retains ordinary scene edits delivered through its operation channel. This is an authored setup and observation record, not a serialized fluid continuation or a renderer performance result.
