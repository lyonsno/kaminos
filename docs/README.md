# Kaminos Docs

Kaminos is a spatial asset kiln: a workbench for turning rough operator intent,
imported evidence, local inference routes, generated outputs, and scene-native
assets into inspectable spatial artifacts without losing source truth.

Current docs:

- [Specimen Conditioning Bench](specimen-conditioning-bench.md) - the product
  flow for fast truth, slow beauty, route attempts, failure cartography, and
  stronger next requests.
- [Route Receipts and Source Truth](route-receipts-and-source-truth.md) - the
  evidence contract that prevents requested routes, effective routes, fallback,
  fixture, partial, failed, and live results from masquerading as each other.
- [WebGPU Truth-Layer Routes](webgpu-truth-layer-routes.md) - local browser
  inference routes such as MoGE depth/normal/pointmap, and how their outputs
  enter the specimen packet as conditioning truth layers rather than candidate
  concept art.
- [Asset Kiln Fire Language](asset-kiln-fire-language.md) - how Beaming's
  volumetric fire substrate should become a truthful route-activity/status
  body for source tiles, route rows, partial outputs, failures, cache recall,
  and promoted assets.
- [Splat Assets](splat-assets.md) - declared splat assets, sidecar correction
  metadata, and render-handoff boundaries.

These documents describe current contracts and near-term direction. They should
not be read as claims that every route already has a live backend. When a route
is fixture, fallback, partial, failed, or request-only, Kaminos must keep that
state visible in receipts, UI, witness reports, and downstream packet state.
